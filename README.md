# Number Guessing Game – Java

A simple console-based Number Guessing Game developed using Core Java as part of the Oasis Infobyte Java Development Internship (OIBSIP).

## Project Overview

The Number Guessing Game is a Java application in which the computer randomly generates a number between 1 and 100. The player needs to guess the generated number within a limited number of attempts.

The game provides hints after each incorrect guess, helping the player identify whether the actual number is higher or lower than their guess.

## Features

- **Random Number Generation:** Generates a random number between 1 and 100 in each round.
- **Multiple Rounds:** The game consists of 3 rounds.
- **Limited Attempts:** Players get a maximum of 10 attempts per round.
- **Guess Feedback:** Displays hints indicating whether the generated number is higher or lower than the entered guess.
- **Score Calculation:** Awards points based on the number of attempts used.
- **Final Score:** Displays the total score after completing all 3 rounds.

## Game Rules

1. The computer generates a random number between 1 and 100.
2. The player gets 10 attempts to guess the number in each round.
3. After every incorrect guess, the game provides a higher or lower hint.
4. If the player guesses correctly, the round score is calculated based on the attempts used.
5. The game continues for 3 rounds.
6. At the end, the total score is displayed.
